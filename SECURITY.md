# Security

Please report a vulnerability privately: **Security → Report a vulnerability** in this
repository. Do not open a public issue for it.

In scope: the Nookast app, its over-the-air updater and the release workflow in
[`.github/workflows/release.yml`](.github/workflows/release.yml). Problems of the PinePods
server itself belong to [PinePods](https://github.com/madeofpendletonwool/PinePods).

Only the latest release is supported: fixes come as a new release, which the app installs by
itself.

Never include your server address, login, password, API key or an unredacted log in a report.

## Русский

Об уязвимостях сообщайте закрыто: **Security → Report a vulnerability** в этом репозитории, не
в открытом issue. Сюда относятся приложение Nookast, его обновление по воздуху и workflow
выпуска. Проблемы самого сервера PinePods — в [PinePods](https://github.com/madeofpendletonwool/PinePods).
Поддерживается только последний выпуск: исправление приходит новым выпуском, и приложение ставит
его само. Не присылайте адрес сервера, логин, пароль, API-ключ и журнал без удаления личных данных.
