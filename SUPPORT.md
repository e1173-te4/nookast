# Getting help

- **Something doesn't work in Nookast:** open an [issue](../../issues/new/choose). The bug form asks
  for the version, device and Android version.
- **A question or an idea:** a [feature request](../../issues/new?template=feature_request.yml) is
  the right place.
- **A problem with the PinePods server itself** (feeds that don't update on the server, sign-in to
  the web app, server settings): ask the [PinePods project](https://github.com/madeofpendletonwool/PinePods).
- **A security problem:** report it privately, see [SECURITY.md](SECURITY.md).

Before you post, look at Settings → Diagnostics in the app: «Check connection» and the shared log
often tell what went wrong. Remove your server address and login from anything you share.

**По-русски:** ошибки и вопросы — в issues; проблемы самого сервера PinePods — в проекте PinePods;
уязвимости — закрыто, по [SECURITY.md](SECURITY.md). Адрес сервера и логин не публикуйте.
